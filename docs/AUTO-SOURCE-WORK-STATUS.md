# Automatic-source work branch

This branch contains new source adapters, historical-profile readers, provider-neutral scenario construction, and their tests. It is a work in progress, not a deployment release. The complete locally tested 0.3 application integration has not been published here: a repository upload operation for the launch-feed provider integration was blocked by the tool before a commit was made.

Do not install this branch as a replacement for the existing container. The main branch and 0.2.0-alpha.1 image remain unchanged. The live-adapter workflow exercises the independent source readers and historical-profile geometry only; it is not a complete application integration test or a release publication workflow.

Sources are distinguished as published directions, third-party estimates, historical webcast ascent analogues, and optional mission simulations. A historical analogue rotated onto a new departure corridor is still an estimate, not the current mission's exact trajectory. Broad fallback scenarios do not establish actual visibility.
