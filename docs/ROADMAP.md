# Roadmap

Current alpha: customizable saved locations, account separation, cached schedules, explicit experimental corridor scenarios, sourced-track import, horizon/solar geometry, observer-grid weather, server-side web-push scheduler, PWA shell, and Unraid templates.

Next: validate real provider responses and phone notification receipt on the deployed instance; connect a legally usable mission-specific trajectory source; build a sourced historical sightings/false-positive test set. Add site/vehicle families only with documented assumptions and coverage tests.

Later: map-pin input, ground-track map, directional/line-of-sight cloud screening, more realistic plume evolution and brightness/detectability, per-location alert-rule overrides, optional native app/AR pointing, and public-service scale/security work. These are plans, not currently available features.
