# Downrange

**The launch isn't local. The view might be.**

A self-hosted, mobile-first rocket launch visibility and space-jellyfish forecasting app, with customizable viewing locations and push notifications.

The first implementation is being imported into this repository. It includes a Python API, installable web interface, Docker packaging, and Unraid templates.

Predictions distinguish modeled geometry from unknown trajectories and do not claim a guaranteed sighting. See the implementation documentation for supported flight profiles and validation status.
